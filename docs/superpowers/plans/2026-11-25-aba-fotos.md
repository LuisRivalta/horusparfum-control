# Aba Fotos Implementation Plan

**Goal:** Tela `/anuncios/fotos` para gerenciar e baixar as fotos de cada perfume.
**Architecture:** Reaproveita `FotosPerfume`; ganha prop opcional `nome` e botões de baixar. Helper puro de nome de arquivo em `lib/anuncios.ts`.
**Tech Stack:** React + TS, Supabase JS, Vitest.
**Spec:** `docs/superpowers/specs/2026-11-25-aba-fotos-design.md`

## Global Constraints
- Sem dependência nova; sem migration.
- Commits sem Co-Authored-By, na main, sem push.

## Review Focus
- Nome com acento/barra ("Asad Bourbon / Lattafa") → arquivo seguro; testado na Task 1.
- URL sem extensão ou com querystring → `jpg` / extensão certa; testado na Task 1.
- Falha no fetch da foto → mensagem de erro, sem travar; testado na Task 2.

### Task 1: `nomeArquivoFoto`
- Modify `frontend/src/lib/anuncios.ts`: `export function nomeArquivoFoto(nome: string, indice: number, url: string): string` (índice base 0 → `-01`).
- Test `frontend/src/lib/__tests__/anuncios.test.ts` (ou arquivo existente): `('Asad Bourbon', 0, 'https://x/a.png')` → `asad-bourbon-01.png`; `('Árabe / Ñ', 9, 'https://x/b')` → `arabe-n-10.jpg`; `('X', 0, 'https://x/c.webp?t=1')` → `x-01.webp`.

### Task 2: botões de baixar em `FotosPerfume` + tela `Fotos`
- `FotosPerfume` prop `nome?: string` (padrão `'foto'`); botão "Baixar foto N" por foto e "Baixar todas" no topo (só com fotos). Erro: "Não foi possível baixar a foto.".
- Create `frontend/src/pages/anuncios/Fotos.tsx` (`export function FotosAnuncios()`), rota `/anuncios/fotos` antes de `/anuncios/:id`, item `{ id: 'fotos', label: 'Fotos', icon: 'box', path: '/anuncios/fotos' }` depois de Controle.
- Tests: em `FotosPerfume.test.tsx`, clicar "Baixar foto 1" chama `fetch('u1')` e cria link com `download="asad-01.jpg"` (com `nome="Asad"`); fetch rejeitado mostra o erro. `Fotos.test.tsx`: escolher perfume mostra o componente de fotos daquele perfume.
- Verificação: `npx vitest run`, `npm run build`. Docs: ANUNCIOS.md (telas), HANDOFF, LOGS.
